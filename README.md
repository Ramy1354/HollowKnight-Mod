# HK Mod Menu

A lightweight trainer and cheat overlay for *Hollow Knight*, built with BepInEx.

---

## Features

- **God Mode:** Keeps your health permanently locked at maximum.
- **Infinite Soul:** Keeps your SOUL vessel charged to cast spells and focus freely.
- **One Hit Kill:** Reduces enemy health so they fall in a single strike.
- **+1,000 Geo:** Instantly grants 1,000 Geo with a single click.

---

## Requirements

- **Hollow Knight** (PC / Steam / GOG)
- **BepInEx 5.x (x64)** installed in your Hollow Knight game directory.

---

## Installation Guide

Follow these steps to install and run the `.dll` mod:

### Step 1: Install BepInEx (If Not Already Installed)
1. Download **BepInEx 5.4.x (x64) (in the Files above)**.
2. Extract all contents of the BepInEx zip directly into your main Hollow Knight folder (where `hollow_knight.exe` is located).
3. Launch the game once to allow BepInEx to generate its folder structure, then close the game.

### Step 2: Install the Mod Files
1. Download the latest release:
   - `MyModMenu.dll`
   - `menu_frame.png`
